# Kicklio Landing Page

A modern, responsive landing page for **Kicklio**, a mobile app built with Kotlin Multiplatform Mobile (KMM).

## About Kicklio

Kicklio is an innovative mobile application that provides seamless cross-platform experience on both iOS and Android devices. Built using Kotlin Multiplatform Mobile technology, it offers native performance with a single codebase.

## Features

- **Lightning Fast**: Optimized performance across all devices
- **Cross-Platform**: One codebase for iOS and Android
- **Reliable**: Secure and stable with regular updates

## Tech Stack

- **Framework**: Next.js 16
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: Ready for Vercel or any static hosting

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the landing page.

## Build for Production

```bash
npm run build
npm start
```

## Deployment

The easiest way to deploy this Next.js app is to use the [Vercel Platform](https://vercel.com/new) from the creators of Next.js.

## Project Structure

- `app/page.tsx` - Main landing page component
- `app/layout.tsx` - Root layout with metadata
- `app/globals.css` - Global styles with Tailwind imports
- `public/` - Static assets

## Customization

To customize the landing page:

1. Update the content in `app/page.tsx`
2. Modify colors and styles using Tailwind classes
3. Add your app screenshots to `public/` and update image paths
4. Update metadata in `app/layout.tsx`
